# SEO Optimization Plan

Status: planned
Owner: CeSaFiu product
Last updated: 2026-05-06

## Goal

Improve organic discovery for students and parents searching for career, path, and university guidance in Romania.

Primary search intents:

- "ce cariera mi se potriveste"
- "test vocational elevi"
- "ce facultate sa aleg"
- "cariere dupa profil"
- "cariere IT / medicina / arta / business"
- "facultati Romania"
- specific career searches such as "asistent medical salariu facultate traseu"

## Current baseline

Already done:

- `sitemap.xml` generated by Next metadata route.
- `robots.txt` generated by Next metadata route.
- localized `/ro` and `/en` routes.
- static career pages under `/[locale]/cariera/[id]`.
- Explore page with careers, paths, and universities.

Gaps:

- No dedicated SEO guide pages for high-intent queries.
- Career pages have limited SEO metadata and structured data.
- No public methodology/about trust pages optimized for search.
- No canonical metadata / hreflang metadata in page HTML beyond sitemap alternates.
- Explore tabs are mostly client-side; useful for users, less specific for search.

## Principles

- Build useful, student-first pages, not keyword-stuffed pages.
- Prefer original explanations, examples, and Romanian context.
- Keep claims defensible: "orientare", "potrivire", "trasee posibile"; avoid diagnostic or guaranteed outcome language.
- Every SEO page should link users into a real product action: start test, explore careers, compare universities, save profile.
- For career/faculty guidance, trust matters: explain methodology, data sources, limitations, and last review date.

## Phase 1: Technical Foundation

1. Add dynamic metadata for career pages.

   For `/[locale]/cariera/[id]`, generate:

   - `title`: `{careerName}: ce face, salariu, traseu si facultati | Ce Sa Fiu`
   - `description`: concise career-specific summary.
   - `openGraph.url`
   - `alternates.canonical`
   - `alternates.languages` for `ro` and `en`.

2. Add metadata for main app pages.

   - `/ro`: "Ce Sa Fiu? Test vocational si ghid de cariera pentru elevi"
   - `/ro/browse`: "Exploreaza cariere, trasee si universitati"
   - `/ro/rezultate`: likely noindex if it depends on local/user-specific data.
   - `/ro/profil`: likely noindex if it depends on local/user-specific data.

3. Revisit `robots.ts`.

   Consider blocking user-specific or low-value pages:

   - `/ro/rezultate`
   - `/en/rezultate`
   - `/ro/profil`
   - `/en/profil`

   Decision needed: if these pages are mostly local/user state, they are poor search landing pages and should be `noindex`.

4. Add structured data.

   - `WebSite` and `Organization` on locale layout or root.
   - `BreadcrumbList` on career pages.
   - `Article` or `WebPage` on SEO guide pages.

5. Improve sitemap.

   Include future SEO guide pages.
   Keep API/auth/consent/token pages out.

## Phase 2: High-Intent SEO Pages

Create dedicated public pages in Romanian first, English later only if useful.

Recommended first pages:

1. `/ro/test-vocational-elevi`

   Target intent: students looking for a vocational/career test.

   Required content:

   - what the test helps with
   - how long it takes
   - what user gets at the end
   - difference between quick scenarios, Holland, Big Five
   - CTA to start recommended test
   - short FAQ

2. `/ro/ce-cariera-mi-se-potriveste`

   Target intent: broad uncertainty / exploration.

   Required content:

   - why career fit is not one fixed answer
   - examples of fit signals: interests, working style, tolerance for structure, people vs systems, creativity
   - 3-step flow: test -> explore -> choose path
   - CTA to test and explore

3. `/ro/ce-facultate-sa-aleg`

   Target intent: students choosing university/faculty.

   Required content:

   - choosing by career direction, not just prestige
   - city, cost, admission, job market, alternatives
   - link to Explore universities
   - examples: IT, medicine, art, business, security/defense

4. `/ro/cariere-dupa-profil`

   Target intent: users searching by personality/vocational profile.

   Required content:

   - explain Holland/RIASEC in plain Romanian
   - explain Big Five as behavior/work-style signal
   - show example archetypes
   - CTA to tests

5. `/ro/facultati-romania`

   Target intent: public directory.

   Required content:

   - browse by city/domain
   - how to compare programs
   - link to Explore universities tab

## Phase 3: Career Page Enrichment

Every career page should become a standalone useful landing page.

Add or expose sections:

- `Ce face`
- `O zi din viata ta`
- `Pentru cine e potrivita`
- `Salariu`
- `Cerere piata`
- `Trasee posibile`
- `Facultati / programe`
- `Skills`
- `Cariere similare`
- `Ultima actualizare`

SEO template:

- H1: career name.
- Intro: 2-3 sentences with concrete Romanian context.
- H2 sections above.
- Internal links to:
  - matching tests
  - related careers
  - paths
  - relevant university/program pages or Explore filters

Example title:

`Asistent medical generalist: ce face, salariu, traseu si scoli | Ce Sa Fiu`

Example description:

`Afla ce face un asistent medical generalist, ce salarii sunt in Romania si UE, ce traseu de pregatire ai si ce alternative poti explora.`

## Phase 5: Trust and E-E-A-T

Add public trust pages:

1. `/ro/despre`

   - who built CeSaFiu
   - mission
   - what the app is and is not

2. `/ro/metodologie`

   - how matching works
   - what tests are used
   - what data is persisted
   - limitations
   - why results are guidance, not diagnosis

3. `/ro/surse-date`

   - salary and demand sources
   - education/program data sources
   - update cadence

These pages matter because career/faculty guidance can affect life decisions. The site should be transparent and cautious.
